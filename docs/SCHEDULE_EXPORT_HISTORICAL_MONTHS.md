# ייצוא חודשים קודמים — שלב ממשק ואישור מיפוי

## התקנה
1. העתק את קבצי src לתיקיות המקור המתאימות.
2. הרץ ב-Supabase SQL Editor את המיגרציה 20261101180000_schedule_excel_historical_approval.sql, **רק אחרי** המיגרציה של תמונות המיפוי החודשיות (20261101170000).
3. הרץ npm run build ובדוק ב-local לפני פריסה.

## בדיקה
1. בחר אוקטובר 2026 ברשימת החודשים (12 חודשים אחורה, חודש נוכחי, חודש הבא).
2. ודא שנטענו פרסומים היסטוריים; הורד Excel ובדוק את כל שורות התפקידים, שמות ושעות.
3. אם המיפוי נכון, לחץ 'בדקתי את הקובץ — אשר מיפוי לחודש זה'. המיפוי נשמר חד-פעמית; אין דריסה דרך הממשק.
4. רענן וודא שמופיעה הודעת מיפוי מאושר.
5. בדוק שהמיפוי המרכזי לא השתנה.

## מגבלות חשובות
- זהו פאץ' של בחירת חודשים היסטוריים ואישור מיפוי בלבד. **לא** איחוד מנוע ה-Excel ב-Edge Function.
- אישור המיפוי אינו שולח קובץ. שליחה ל-Teams נעשית רק בלחיצה יזומה, לאחר אישור.
- RPC מאמת הרשאה ואת קיום פרסום חודשי כלשהו, אך אינו מוכיח שכל שלושת הלוחות פורסמו או שקובץ Excel נכון. נדרשת בדיקה ידנית.
- הפונקציה האוטומטית של ארכיון אוקטובר אינה מחוברת עדיין למיפוי זה. אין להפעיל אותה עד לשלב האיחוד.
- קוד הפאץ' לא נבדק בבנייה מלאה בסביבה זו.
